1. About the App

Hours — Time Zone Converter is an independently developed, free iOS utility for time zone reference. It has no subscriptions, in-app purchases, paid features, or advertising. The App allows users to save cities and compare their time zones.

Key features include:

  • viewing current time in multiple cities;
  • adjusting a shared time offset using a rotary dial interface;
  • adding cities from a built-in database;
  • searching for cities using Apple MapKit services;
  • optionally using the device’s location to suggest the current city;
  • displaying weather information and estimated sunrise and sunset times for selected cities;
  • visualizing cities on the World Map and using Basic, Compact, or Cards city views;
  • viewing saved cities in supported widgets;
  • creating calendar events in Apple Calendar by explicit user action;
  • creating reminders in Apple Reminders by explicit user action;
  • scheduling local notifications on the device;
  • renaming, reordering, and deleting cities;
  • switching time format (12-hour / 24-hour); and
  • switching appearance mode (system / light / dark).
